
# Fullstack E-Commerce - .NET & React

A personal full-stack e-commerce web application built as a portfolio project using ASP.NET Core Web API, React, SQL Server, Entity Framework Core, and JWT authentication.

## Features

- User registration and login
- JWT authentication
- Admin and Customer role-based authorization
- Product CRUD operations
- Category management
- Shopping cart
- Checkout and stock management
- Customer order history
- Admin order management
- Order status updates
- Product search
- Category and price filtering
- Product sorting
- Pagination
- Protected frontend routes

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- React Router
- Axios

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- ASP.NET Core Identity
- JWT Authentication

### Database
- Microsoft SQL Server

## User Roles

### Customer
Customers can browse products, search and filter products, manage their shopping cart, place orders, and view their order history.

### Admin
Admins can manage products and categories, view customer orders, and update order statuses.

## Running Locally

### Backend

Open the backend solution in Visual Studio and run the ASP.NET Core Web API.

### Frontend

```bash
cd Frontend-React
npm install
npm run dev
```
